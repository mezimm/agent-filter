# Default allowlist: an OPTIONAL curated set of hosts an agent commonly needs
# to read — documentation, package registries, standards, references, open
# data, and major publications. Never loaded automatically: the operator
# imports it from the panel's Add page (source 'default', permanent), and can
# remove the whole imported set from the same page. Format: one "host [port]"
# per line, port defaults to 443.
#
# Curation rules (the same doctrine as the panel's wildcard dialog):
#
#   - Exact hostnames only. Wildcards are refused by the importer — they stay
#     a per-entry human ceremony. www.X and X are one entry at every depth:
#     matching folds a leading www into the bare domain (unless the remainder
#     is a public-suffix zone), so bare domains here cover their www forms.
#   - Every registrable domain here is controlled by a single organisation.
#     Nothing where a stranger can sign up and get their own hostname.
#     An exact host under a shared domain (a project's own github.io page)
#     is as trustworthy as that specific owner, and is never grounds to
#     approve the surrounding wildcard.
#   - Deliberately absent, whatever their popularity:
#       mail and SMS providers (reach any recipient on earth: gmail,
#         sendgrid, mailgun, twilio);
#       chat and webhook ingestion endpoints (discord.com, hooks.slack.com,
#         api.telegram.org);
#       form and survey collectors (docs.google.com carries Google Forms;
#         typeform, surveymonkey, jotform);
#       file-drop, paste, and inspection services (pastebin, imgur, dropbox,
#         drive.google.com, transfer.sh, mega, virustotal, webhook.site);
#       URL shorteners (bit.ly, t.co, tinyurl);
#       tunnel and relay vendors (ngrok, localtunnel, gradio.live, zerotier);
#       push/notification relays (ntfy.sh, pushover);
#       public DoH resolvers (dns.google, cloudflare-dns.com, dns.quad9.net —
#         free lookups through an approved name are a DNS tunnel);
#       web-based fetch and lookup proxies that make a third party retrieve
#         or resolve an agent-chosen URL or name (translate proxies, web
#         dig/whois like mxtoolbox, page-test and screenshot services like
#         webpagetest or urlscan — each is a DNS-tunnel or SSRF channel
#         laundered through a reputable host);
#       code-sharing sandboxes whose share-links are anonymous drop-boxes
#         (pastebin-class: codepen, jsfiddle, codesandbox, godbolt short
#         links, replit);
#       stranger-run hosting and object storage (github.io, gitlab.io,
#         pages.dev, workers.dev, netlify.app, vercel.app, herokuapp.com,
#         s3.amazonaws.com, storage.googleapis.com, blob.core.windows.net,
#         cloudfront.net, web.app, firebaseapp.com, wixsite.com, repl.co,
#         glitch.me, onrender.com, fly.dev, up.railway.app, hf.space,
#         streamlit.app, notion.site, substack.com subdomains).
#     Approve any of those individually, deliberately, in the panel — never
#     by widening this file.
#   - Hosts that serve stranger-authored content read-only (github.com,
#     stackoverflow.com, archive.org, huggingface.co, reddit.com) are
#     included: reading hostile content is this design's accepted baseline;
#     giving it a drop-box is not.
#
# The starter list (starter-allowlist.txt) already carries the guide's own
# needs — github.com, pypi.org, registry.npmjs.org and friends — so they are
# not repeated here. Re-import after editing: only missing entries are added.
